# curfew

**"A deadline-aware fork-join model where multiple threads run in parallel, but only those that finish before a specified absolute clock time are joined and their results collected. Threads still running after the deadline are ignored or left to finish in the background, allowing time-bounded parallelism without blocking past the deadline."**
